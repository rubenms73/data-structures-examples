# Direct and sequential access

An interactive comparison of a **music CD** and a **music cassette tape**.

Download [direct-sequential-access.html](direct-sequential-access.html) using
GitHub's **Download raw file** button, then open the saved file in a browser.
The animation runs offline without installation or external dependencies.
GitHub displays the HTML source rather than running it.

Select track **6**, wait for both devices to arrive, then select track **2**.
The CD seeks directly to the selected song. The cassette winds through the
intervening tape, forwards or backwards. You can select another track while
it is moving. Keyboard navigation and reduced-motion preferences are supported.

Random access means access to a chosen position; it does not mean shuffle.
A CD can also play songs sequentially. The numbered circular bands are a
schematic representation of songs, not separate physical grooves.
The animation illustrates access patterns, not real device timings or a
complexity benchmark.
