Practical Exam A (28 October 2026) - solution

ExamA.pdf is the handout. ds.UniqueLinkedCollection is the solution, app.App is
the main program asked for in the handout, and tests.UniqueLinkedCollectionTest
holds the JUnit tests supplied in the exam.

Windows: run.cmd / run.cmd test
PowerShell: .\run.ps1 / .\run.ps1 test
macOS or Linux: bash run.sh / bash run.sh test
Eclipse and VS Code: import/open this folder and run app.App or the JUnit tests.
Both java and javac must be available.
