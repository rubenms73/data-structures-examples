# Practical exam solutions

Solutions to the practical exams of Data Structures, grouped by academic year.
Each exam folder contains the handout and a complete, runnable solution project:
the class to implement, the main program `app.App` and the JUnit tests that were
supplied in the exam.

- [2026–2027](2026-2027/README.md)

Try the exam on your own first, using the handout, and only then compare your
work with the solution. Passing the tests is not enough: the handout also asks
for a specific representation, costs and a main program.
